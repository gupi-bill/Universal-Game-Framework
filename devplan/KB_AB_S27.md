## 实验设计

离线 mock 环境**没有真实游戏胜负**，无法测真实胜率。改测一个**离线可测、
语义指向存活率**的代理指标：

> **在「需要谨慎」的局面下，决策是否采取保守动作（defend）。**

机制依据（读源码得出，非臆测）：
- 知识唯一能改变动作的落点在 `knowledge_loop.decide_action`：
  `decision==cautious_fight` 且（hp<0.6 或 threat>1.0）且命中 retreat/keep_distance → `defend`
- 无知识时，`agent_main._fallback_decide` 对 cautious_fight 返回 `attack`（激进）

对照组（baseline，无知识）vs 实验组（learned，有知识），扫描 3×4×5=60 种局面，
筛出 48 个「危险局面」。

## 实测结果

| 指标 | 值 |
|------|-----|
| 危险局面样本数 | 48 |
| 对照组 保守率 | **41.67%** |
| 实验组 保守率 | **66.67%** |
| 差值 (learned − baseline) | **+0.25** |
| Bootstrap 95% CI | **[0.0625, 0.4375]** |
| 显著为正 | ✅ 是（CI 不含 0） |

## 结论

- ✅ **知识确实改变动作**：命中知识后，危险局面的保守动作率从 41.67% 升至 66.67%，
  差值 +25 个百分点，Bootstrap 95% 置信区间不含 0 → **统计显著**。
- 这闭合了 S18 链路中「知识 → 动作」的最后一段，**机制层面 P2 成立**。

## ⚠️ 诚实边界（必读）

**本实验证明的是「知识改变动作」，不是「改变的动作提升胜率」。**
- 「保守动作率上升」是**代理指标**，语义上指向存活率，但**不等于**实测胜率。
- 真实胜率差异需**真机环境**（真实游戏窗口 + 真实对局结果）才能测，属环境性未验证。
- 因此 **S18 判据（真实 A/B 胜率）仍为 🟡**，本 S27 是其**离线可测的前置证据**，不越权升级 S18。
