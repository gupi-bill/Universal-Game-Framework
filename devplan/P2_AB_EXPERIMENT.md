# P2 实证：知识闭环到底有没有用（P2_AB_EXPERIMENT）

> 执行时间：2026-09-30 ｜ 环境：离线 arena 模拟，无 LLM/VLM/显示器
> 交付：`arena.py`、`ab_experiment.py`、`tests/test_arena.py`（18 用例）、本文
> 用例总数：991 → **1009 全绿**

## 1. 结论先行（诚实版）

> **P2「进化闭环成立」目前未成立。当前知识库的内容会让决策变差。**

| 指标 | 数值 |
|------|------|
| 决策层的价值（no_kb − baseline） | **+16 回合** ✅ |
| 知识的额外价值（kb − no_kb） | **−5 回合** ❌ |
| 定位到的有害标签 | `retreat` / `keep_distance` |
| 存活率 | 三组均 0%（arena 太狠，见 §5 局限） |

这不是「玄学」，脚本能**自动定位到具体是哪条标签在拉低结果**。

## 2. 为什么以前证明不了

`devplan/KB_LOOP_S18.md` 已经证明「检索命中率 100%、引用率 100%」。
但那只说明知识**流到了决策**，不说明决策**变好了**。

而且当时的实验环境根本无从比较：`perception.mock` 的场景是固定的
（HP 恒 100、敌人恒 6、坐标按 vx/vy 往返漂移）。无论知识库是空的
还是塞满战术，跑出来的轨迹**逐帧相同** —— 那种环境证明不了任何事。

## 3. 新增：arena（可结算的对局）

`perception.mock` 继续负责「链路通不通」，`arena.py` 负责「决策好不好」。

| 能力 | 为什么需要 |
|------|-----------|
| seed 驱动 | 同 seed 同动作 → 同结果，不同 seed → 不同对局，统计才有意义 |
| 有代价 | 敌人接触扣血，血空则该局失败 —— 动作选择才能产生后果 |
| 难度爬升 | 敌人加速/增援，不加的话早死或不死，测不出差异 |
| 无 framebuffer | 玩家被包围时无处可逃也不合理 —— 这正是 §6 那个 bug 的放大器 |

自检（`python arena.py --self-test`）四关：确定性 / 差异性 / 因果链 / 死亡结算。

## 4. 实验发现的两个真 bug

### D1 · `apply_tactics` 把「撤退」改写成「原地蹲守」

```python
if decision == "retreat":
    return "defend"        # ← 语义错误
```

在 arena 里逐回合统计决策分布，问题一目了然：

```
无知识: {'fight': 56, 'cautious_fight': 9, 'retreat': 2}
有知识: {'fight': 56, 'defend': 9,         'retreat': 2}
                  ↑ cautious_fight 被改成了 defend
```

而 `_tactical_spot` 里：
- `cautious_fight` → 往场地边缘但不正对敌人质心
- `defend` → 往离最近威胁最远的一侧

被包围时后者更糟 —— **知识反而让 Agent 更保守地站在原地挨打**。

**修复**：撤退类知识只影响「谨慎战斗」，不再把撤退本身变成防守。

### D2 · 组队经验在单机局生效

```python
if t & {"focus_fire", "protect_ally"}:
    return "attack"          # ← 没检查有没有队友
```

单机局检索到「保护队友」类经验属于**知识串味**。
`knowledge_md` 按游戏分区解决了跨游戏串味，但没解决**同游戏内单机/组队串味**。

**修复**：`apply_tactics` 增加 `has_allies` 参数，队友类标签默认不生效
（「拿不准就当没有队友」—— 错误加成的代价高于漏掉的加成）。
`decide_action` / `decide_with_knowledge` / `agent_main` 全链路透传。

### 修复效果

```
修复前:  kb − no_kb = −8 回合
修复后:  kb − no_kb = −5 回合
```

改善了但仍是负的 —— 因为 `retreat`/`keep_distance` 这两条标签
**在这个场景本身就无适用面**（见 §5）。

## 5. 为什么仍然是负的（诚实的部分）

逐条标签单独探针（20 组 × 200 回合，回合中位数）：

| 知识标签 | 回合中位 | 对照 |
|---------|---------|------|
| 空知识库 | 75.0 | +0.0 |
| 撤退/保持距离类 | **70.0** | **−5.0** ← 拉低 |
| 集火类 | 75.0 | +0.0 |
| 保护队友类 | 75.0 | +0.0 |

**结论**：`knowledge_md/space_invaders/` 里的 4 条标签
（`retreat` / `keep_distance` / `focus_fire` / `protect_ally`）
**没有一条在这个 arena 场景下适用** —— 这个场景是「单机被围攻」，
而这 4 条分别属于「组队」「集火」「撤退时机」等别的局面。

换句话说：**知识库存的是战术名词，不是「对这一局面真的有用的经验」。**
这正是 P2 命题没被满足的真正原因 —— 不是闭环断了，
是**入库的东西本身没有信息量**。

## 6. 三组都 0% 存活

即使调难度，三组存活率仍全是 0/30。

原因：arena 里敌人从四面八方靠拢，`contact_radius` 之内就是挨打。
玩家速度 190 px/s 逃不掉围堵，最终必死。

这**不影响「回合中位数」这个指标**（能比出高低），但
**存活率这个指标目前在 arena 里没有区分度**，脚本输出时应该注意：

> 三组存活率都是 0%，说明这个环境目前只能比「撑多久」，不能比「能不能赢」。

后续要让存活率有区分度，需要给 arena 加「可撤离目标点」或「远程输出手段」。

## 7. 下一步（按优先级）

1. **让知识库存局面相关的经验，而不是战术名词。**
   现在 `extract_tactics` 是关键词匹配 → 抽出 `retreat` 这种词。
   改成：条目必须带「适用条件」（如「被 ≥5 个敌人包围时」）才生效。
   这是 P2 从「无增益」到「有增益」的关键。
2. **给 arena 加撤离目标**，让存活率有区分度。
3. **换 seed 批次复现**：`--offset 1000`，确认 −5 回合不是这批 seed 的巧合。
4. **上真机**：本实验全在模拟环境，不能替代实机验证。

## 8. 复现方式

```bash
python ab_experiment.py --n 20 --rounds 200    # 主实验
python ab_experiment.py --n 20 --offset 1000   # 换批次复现

```
